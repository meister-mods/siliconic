# Siliconic

[English](README.md) | 한국어

> 실리콘을 정제하고, 웨이퍼 회로를 설계해 Minecraft의 레드스톤 시스템을 확장하는 기술 모드입니다.

Siliconic은 자원 채굴부터 반도체 생산, 논리 게이트 조립, 집적회로 설계까지 이어지는 새로운 기술 진행 과정을 추가합니다. 플레이어는 전력으로 작동하는 여러 설비를 구축하고 직접 설계한 웨이퍼를 더 높은 집적도의 회로에 활용하여 점차 복잡한 자동화 시스템을 만들 수 있습니다.

## 주요 특징

- 조실리콘과 고순도 실리콘으로 이어지는 반도체 생산 과정
- NOT, AND, OR, XOR, 버퍼 등 기본 논리 소자
- SSI부터 ULSI까지 단계적으로 발전하는 웨이퍼 체계
- 배선, 입출력 핀, 신호 방향을 조합하는 회로 설계
- 완성한 하위 웨이퍼를 상위 웨이퍼에 넣어 재사용하는 계층형 집적
- 웨이퍼 복제, 반전과 회로 운용을 돕는 보조 설비
- 석탄 발전기와 기계별 전력 소비를 포함한 에너지 시스템
- 밀폐 상태 감지, 청정도 유지, 코팅 내벽 보너스와 발전기를 제외한 기계의 클린룸 내
  작동 제한을 갖춘 클린룸 시스템
- 청정도에 따라 조실리콘, 고순도 실리콘, 웨이퍼와 논리 게이트가 불량품으로 변하는
  오염 확률
- 실리콘 처리기, 웨이퍼 제조기, 게이트 조립기와 웨이퍼 복제기의 3×3 출력 저장 공간
- 싱글플레이와 멀티플레이 지원
- 선택 사항인 JEI 연동을 통한 기계 제조법 확인

## 기본 진행 흐름

1. 네더 석영과 각종 금속 등 필요한 자원을 확보합니다.
2. 발전기와 실리콘 처리 설비를 구축합니다.
3. 실리콘을 정제하고 웨이퍼와 논리 게이트를 생산합니다.
4. 웨이퍼 스테이션에서 원하는 논리 회로를 설계하고 이름을 지정합니다.
5. 완성된 웨이퍼를 레드스톤 장치에 연결하거나 더 높은 등급의 웨이퍼에 집적합니다.
6. 회로를 복제하고 확장하며 더욱 복잡한 자동화 설비를 구성합니다.

정확한 재료 구성과 기계별 제조법은 게임 내 JEI 화면에서 확인하는 것을 권장합니다.

## 실행 환경

| 항목 | 버전 |
| --- | --- |
| Minecraft | 1.20.1 |
| Minecraft Forge | 47.x (47.4.10 기준 개발) |
| Java | 17 |
| Just Enough Items | 15.20 이상, 선택 사항 |

## 설치

1. Minecraft 1.20.1용 Forge를 설치합니다.
2. Siliconic 모드 파일을 Minecraft의 `mods` 폴더에 넣습니다.
3. 제조법 안내가 필요하다면 같은 버전의 JEI도 함께 설치합니다.
4. Forge 프로필로 게임을 실행합니다.

멀티플레이에서는 서버와 접속하는 모든 플레이어가 동일한 Siliconic 버전을 사용해야 합니다. JEI는 클라이언트에만 설치해도 됩니다.

## 개발용 빌드

JDK 17 환경에서 다음 명령으로 빌드할 수 있습니다.

```powershell
.\gradlew.bat build
```

완성된 모드 파일은 `build/libs` 폴더에 생성됩니다. 개발 클라이언트는 `.\gradlew.bat runClient`로 실행할 수 있습니다.

## 개발 상태

Siliconic은 현재 초기 개발 단계입니다. 새로운 웨이퍼, 설비와 회로 기능이 계속 추가될 예정이며 개발 과정에서 제조법과 밸런스가 변경될 수 있습니다. 중요한 월드에는 새 버전을 적용하기 전에 백업을 권장합니다.

문제 제보와 제안은 [GitHub Issues](https://github.com/meister-mods/siliconic/issues)를 이용해 주세요.
