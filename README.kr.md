# Siliconic

[English](README.md) | 한국어

> 실리콘을 정제하고 클린룸을 설계해, 프로그래밍 가능한 웨이퍼 안에 실제로 동작하는 레드스톤 회로를 만드세요.

Siliconic은 반도체 제조와 집적회로 설계를 중심으로 하는 Minecraft Forge 1.20.1 기술 모드입니다. 원재료를 가공하는 산업 공정에서 시작해 클린룸 건설, 논리 게이트 생산, 레드스톤과 직접 상호작용하는 재사용 가능한 웨이퍼 회로로 발전합니다.

## 핵심 특징

### 반도체 생산

- 석영을 금속급 실리콘으로 환원한 뒤 염화, 증류, 지멘스 증착을 거쳐 고순도 다결정 실리콘을 생산합니다.
- 고온 화학 장비의 마그마 탱크를 마그마 크림, 마그마 블록 또는 용암으로 충전해 공정열을 공급합니다.
- 사염화규소, 수소, 염화수소를 폐쇄형 공정으로 재순환해 새 시약 소비를 줄입니다.
- NOT 등의 논리 게이트와 SSI부터 ULSI까지 다섯 단계의 웨이퍼를 생산합니다.
- 제조, 정제, 복제, 반전과 재료 회수에 특화된 전력식 장비를 운용합니다.
- 오염된 공정 생산물을 버리는 대신 재처리하여 유용한 원재료를 회수합니다.

### 프로그래밍 가능한 웨이퍼 회로

- 입출력 핀을 설정할 수 있는 9×9 웨이퍼 격자에서 회로를 설계합니다.
- 서로 다른 신호 감쇠 특성을 가진 레드스톤, 구리, 납, 은, 금 배선을 사용합니다.
- NOT, AND, OR, XOR, 버퍼, 강하, 스위치 게이트를 조합합니다.
- 래치와 플립플롭처럼 피드백을 이용하는 순차회로를 구현합니다.
- 완성한 하위 등급 웨이퍼를 상위 등급 웨이퍼에 넣어 복잡한 설계를 재사용하고 조합합니다.
- 웨이퍼 가드와 레드스톤 클럭기를 이용해 완성한 웨이퍼를 월드의 레드스톤 장치로 운용합니다.

### 클린룸 설계

- 전력으로 작동하는 클린룸 컨디셔너가 감시하는 밀폐 공간을 건설합니다.
- 방이 열리거나 오염되면 하락하고 밀폐 상태가 유지되면 회복되는 청정도를 지속적으로 관리합니다.
- 일반적인 방에서는 기본 청정도 한계까지 회복하고, 내벽을 코팅해 최대 100%에 가까워지도록 개선합니다.
- 한 공간에 설치한 여러 컨디셔너를 동기화하여 공간을 함께 감시하고 정화 효율을 높입니다.
- 열린 문이 양쪽의 밀폐 공간을 일시적으로 합치도록 구성하여 클린룸을 유지하는 에어록을 만들 수 있습니다.
- 방진복으로 작업자에 의한 오염을 줄이고, 화로와 발전기 같은 오염 장비는 정밀 작업 공간 밖에 배치합니다.
- 선공정 장비는 모두 클린룸 오염원이므로 밖에 배치하고, 청정도가 낮은 클린룸에서는 웨이퍼와 게이트 공정의 오염 위험이 높아집니다.

### 전력과 자동화

- 석탄 발전기로 전력을 생산하고 표면 부착형 전력 케이블망으로 공급합니다.
- 연결 순서에 따라 한 기계만 먼저 채우지 않고, 가용 전력을 여러 장비에 공평하게 분배합니다.
- 전용 사용자 인터페이스에서 장비의 전력, 진행도, 입출력과 동작 상태를 확인합니다.
- 작업물과 재료 슬롯은 장비 안에 안전하게 유지하면서 호퍼로 생산 과정을 자동화합니다.
- 선택 사항인 JEI 연동으로 장비 공정과 필요 재료를 확인합니다.

## 기본 진행 흐름

1. 네더 석영, 탄소, 은, 납, 구리 등 필요한 자원을 확보합니다.
2. 실리콘 전기로에서 석영과 목탄을 환원해 금속급 실리콘을 만들고 슬래그를 재처리합니다.
3. 염화 반응기와 증류탑에서 금속급 실리콘을 고순도 트리클로로실란으로 정제합니다.
4. 지멘스 증착 반응기에서 고순도 다결정 실리콘을 만들고, 재순환기로 사염화규소·수소·염화수소를 되돌립니다.
5. 선공정 라인 밖에 밀폐된 클린룸을 건설하고 컨디셔너에 전력을 공급합니다.
6. 빈 웨이퍼와 논리 게이트를 제조하고 웨이퍼 조립기에서 회로를 완성합니다.
7. 완성한 웨이퍼를 운용·복제·반전·집적하고 전체 생산 라인을 자동화합니다.

정확한 조합 배치와 장비별 공정은 게임 내 JEI 화면에서 확인하는 것을 권장합니다.

### 선공정 장비 운전 차이

| 장비 | 고유 운전 요소 | 자동화 신호/실패 결과 |
| --- | --- | --- |
| 실리콘 전기로 | 소모품인 탄소 전극을 사용하며 장입, 최대 출력 아크, 환원 용융, 출탕 순으로 전력 소비가 달라집니다. 전극이 심하게 마모되면 슬래그가 더 생깁니다. | 진행도에 따라 비교기 출력이 상승합니다. |
| 염화 반응기 | 마그마로 목표 온도 450까지 승온하고 반응 중 압력이 쌓입니다. | 출력이 막혀도 반응을 마치며 압력이 한계에 닿으면 공정물을 비상 배출해 잃습니다. |
| 트리클로로실란 증류탑 | 따뜻한 상태로 연속 운전할수록 안정도가 올라 고순도 모드의 처리 시간이 단축됩니다. 고처리량 모드는 4단위 중 3단위를 두 배 빠르게 정제하고 나머지를 잔류물로 분리합니다. | 잔류물은 재순환기에 다시 넣어 조 TCS 1단위로 회수할 수 있습니다. |
| 지멘스 증착 반응기 | 석영 증착 필라멘트를 종자로 사용하고 예열, 핵생성, 봉 성장, 제어 냉각을 거칩니다. | 정전 등으로 중단해야 할 때 UI에서 부분 성장 봉을 회수해 후속 배치로 복구할 수 있습니다. |
| 클로로실란 재순환기 | 사염화규소와 수소 또는 증류 잔류물을 조 트리클로로실란으로 되돌립니다. | 청색 슬롯은 조 TCS, 황색 슬롯은 HCl, 보라색 슬롯은 기타 부산물 전용입니다. 비교기 신호 10은 수소 부족, 15는 출력 막힘을 뜻합니다. |

고온 장비는 마그마 탱크의 열량을 써서 승온하고 운전 중 열손실을 보충합니다. 마그마 크림은 2,000, 마그마 블록은 8,000, 용암 양동이는 16,000 열량을 공급하며, 공정 투입 슬롯은 배치가 시작되면 완료 또는 회수까지 잠깁니다.

## 설치

1. Minecraft 1.20.1용 Forge를 설치합니다.
2. Siliconic 모드 파일을 Minecraft의 `mods` 폴더에 넣습니다.
3. 게임 안에서 조합법과 공정 안내를 보고 싶다면 호환되는 JEI를 함께 설치합니다.
4. Forge 프로필로 게임을 실행합니다.

멀티플레이에서는 서버와 접속하는 모든 플레이어가 동일한 Siliconic 버전을 사용해야 합니다. JEI는 해당 화면을 사용할 클라이언트에만 필요합니다.

## 개발용 빌드

JDK 17 환경에서 다음 명령으로 빌드할 수 있습니다.

```powershell
.\gradlew.bat build
```

완성된 모드 파일은 `build/libs` 폴더에 생성됩니다. 개발 클라이언트는 `.\gradlew.bat runClient`로 실행할 수 있습니다.

## 개발 상태

Siliconic은 현재 1.0 이전 개발 단계입니다. 버전 사이에 월드 데이터 형식, 조합법, 밸런스와 장비 동작이 변경될 수 있으므로 중요한 월드는 업데이트 전에 백업해 주세요.

문제 제보와 제안은 [GitHub Issues](https://github.com/meister-mods/siliconic/issues)를 이용해 주세요.
