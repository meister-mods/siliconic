# Machine interface texture drafts

기존 `machine_frame_top.png` 및 `machine_frame_side.png` 위에 합성할 목적으로 만든 인터페이스 시안입니다. 현재 블록 모델이나 텍스처에는 연결되어 있지 않습니다.

## 파일 구성

- `16x16/`: 실제 사용을 전제로 정리한 16×16 RGBA PNG 텍스처 10장
- `preview.png`: 투명 영역을 체크무늬로 표시한 16배 확대 비교 이미지

| 장비 | 전면 인터페이스 | 윗면 인터페이스 |
| --- | --- | --- |
| 웨이퍼 조립기 | 웨이퍼 소켓, 방사형 클램프, 청록 상태 링 | 원형 작업대, 십자 정렬선, 4방향 클램프 |
| 게이트 조립기 | 2입력·1출력 배선과 중앙 칩 소켓 | PCB 작업대, 구리 접점, 모서리 고정구 |
| 웨이퍼 제조기 | 웨이퍼 챔버, 가공 헤드, 정렬선 | 리소그래피 헤드, 가이드 레일, 식각 격자 |
| 웨이퍼 반전기 | 중앙 대칭축과 반대 방향 신호 | 좌우 분할 웨이퍼와 대칭 표식 |
| 웨이퍼 복제기 | 원본·복제 웨이퍼와 전송 표시 | 대각선으로 배치한 두 웨이퍼와 전송 신호 |

## 생성 기준

OpenAI 내장 ImageGen으로 장비별 전면·윗면 시안을 각각 생성하고, 실제 알파 채널이 있는 투명 오버레이로 배경을 추출했습니다. 이후 16×16로 축소하고 프레임과 어울리는 금속 회색, 청록, 주황, 녹색의 제한 팔레트로 정리했습니다.

공통 프롬프트 기준은 다음과 같습니다.

- Minecraft용 16×16 논리 픽셀 인터페이스
- 기존 머신 프레임은 스타일 참조로만 사용
- 프레임, 블록 배경, 글자, 숫자, 워터마크 제외
- 인터페이스 외부는 실제 투명 알파
- 전면과 윗면에서 장비의 기능이 서로 구분되는 최소 기호 사용
